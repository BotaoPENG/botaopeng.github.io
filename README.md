# Botao Peng's homepage

The site is served directly from the repository root by GitHub Pages. It uses
HTML, CSS, and browser JavaScript.

- Edit the profile, news, publications, and other homepage content in `index.html`.
- Edit the homepage styles in `assets/css/home.css`.
- The responsive navigation and Follow menu are in `assets/js/home.js`.

To preview the site locally, run the following command from the repository
root and open [localhost:8000](http://localhost:8000/).

```sh
python3 -m http.server 8000
```

Existing secondary pages are preserved as static snapshots at their previous
URLs. They use the archived `assets/css/main.css` and `assets/js/main.min.js`
assets alongside their original images, fonts, and files. See `LICENSE` for
the original theme attribution.
